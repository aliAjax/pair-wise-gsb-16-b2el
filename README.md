# hxwl-01 助听器回访记录台

助听器带回家后的回访登记台：按耳记录充电前后电量、续航和断连次数，异常耳自动进入待检流程。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5101

## 功能

- **按耳登记回访**：左 / 右耳分别记录充电前电量、充电后电量、续航小时、断连次数
- **自动待检判断**：续航不足 10 小时、充电后两耳电量差超过 20%（电量较低的一侧）、一天断连达到 3 次，该耳进入待检并保留触发时的原始输入
- **调机限制**：检测结论登记回来前，待检的耳不能新建调机（表单内实时提示并禁用提交）
- **寄回 / 换机**：记录处理方式与新旧序列号
- **设备经历查询**：按序列号查回访、待检、调机、寄回 / 换机全部经历，旧设备历史仍可追溯
- **本机保存**：所有数据存于 localStorage，重开页面后记录、待检项和换机经过都在

## 代码分层

| 文件 | 职责 |
| --- | --- |
| `src/types.ts` | 资料：全部数据结构 |
| `src/rules.ts` | 判断：待检规则与调机限制（纯函数） |
| `src/storage.ts` | 本机保存：localStorage 读写 |
| `src/App.tsx` | 界面：渲染与交互 |
