# hxwl-01 助听器回访记录台

助听器带回家后的回访登记与问题跟踪：充电盒掉电、单耳断连、寄回换机一屏记录。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5101

## 功能

- **按耳登记回访**：充电前后电量、续航小时、当天断连次数，左右耳分开录入
- **自动待检判定**：续航不足 10 小时、充电后两耳电量差超过 20%、一天断连达 3 次，任一命中该耳即进入待检，并保留触发时的原输入快照
- **调机拦截**：待检耳在检测结论登记前不能新建调机，界面实时提示拦截原因
- **寄回 / 换机登记**：记下新旧序列号；按序列号可还原旧设备的装机、寄回、换下经历
- **本机保存**：全部台账写入 localStorage，重开页面记录、待检项和换机经过都在

| 层 | 位置 | 职责 |
